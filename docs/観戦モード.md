# 観戦モードの使い方

## 基本動作

`LoLAPIGet.exe` を起動すると、観戦データの入力画面が表示され、最上段に試合時間が表示されます。画面上部の「観戦モード」トグルがオンのときだけ入力欄が表示され、入力した観戦データがAPIから返されます。トグルがオフの場合は入力欄が隠れ、観戦データは返されません。設定は `settings.ini` に保存されます。

トグルがオンでも、Live Client Data APIで観戦中と判定されない間は入力欄を表示したまま編集操作を無効にします。観戦モードがオフの間、観戦中はトップバーとオブジェクトタイマーを非表示にします。

## データの入力

観戦中は、ORDER/CHAOS別のオブジェクト取得数を `[アイコン] - 数 +` の並びでボタンまたは数値入力により更新します。

ドラゴンは `[アイコン] - 数 [種類アイコン...]` の並びで、種類アイコンは通常サイズの約2/3で表示されます。種類アイコンを押すと取得数が更新され、4体目まで履歴にもアイコンが追加されます。取得履歴は「取得履歴」の右隣にアイコンを並べ、履歴アイコンは種類ボタンと同じサイズです。両チーム合計4体取得すると通常種のボタンは無効になり、エルダーのみ選択できます。

ドラゴン/バロンの取得数を増やすと、Live Client Data APIから取得した試合時刻が内部の最終撃破時刻に設定されます（画面には表示しません）。バロン撃破時はバロンバフ終了時刻を撃破時刻の3分後に、両チーム合計5体目以降のドラゴン撃破時はエルダーバフ終了時刻を撃破時刻の150秒後に自動設定します。バフ終了時刻などの入力値は変更時に自動保存されます。時刻は試合内の `MM:SS` 形式です。

ドラゴン/バロンの次回出現時刻は、取得数と最終撃破時刻から既存のタイマー規則で計算されます。ヘラルドとヴォイドグラブは取得数が1以上になると、オブジェクトタイマー上で撃破済みとして扱われます。

## 保存とリセット

入力データは `LoLAPIGet.exe` と同じフォルダーの `json/spectator_data.json` に保存されます。既存の `spectator_data.json` が実行ファイルと同じフォルダーにある場合は、起動時に `json` フォルダーへ引き継ぎます。

Live Client Data APIから試合データを取得できなくなっても入力内容は保持され、試合時間が前の観測値から巻き戻った（次の試合が始まった）時点で自動リセットします。通常のプレイではこの手動データは使われません。「全データをクリア」で手動リセットもできます。
