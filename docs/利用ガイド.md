# LoL Overlay 利用ガイド

初めての導入は[README](../README.md)、OBSの設定は[OBS設定手順](OBS設定手順.md)を参照してください。

## 言語設定

`LoLAPIGet.exe` と同じフォルダーの `settings.ini` をテキストエディターで開き、League of Legendsクライアントの言語に対応するコードを設定します。配布時は日本語（`ja_JP`）です。たとえば英語（アメリカ）では次のようにします。

```ini
[settings]
language = en_US
```

使用できる言語コード:

| --- | --- | --- | --- |
| `cs_CZ` | チェコ語 | `el_GR` | ギリシャ語 |
| `pl_PL` | ポーランド語 | `ro_RO` | ルーマニア語 |
| `hu_HU` | ハンガリー語 | `en_GB` | 英語（イギリス） |
| `de_DE` | ドイツ語 | `es_ES` | スペイン語（スペイン） |
| `it_IT` | イタリア語 | `fr_FR` | フランス語 |
| `ja_JP` | 日本語 | `ko_KR` | 韓国語 |
| `es_MX` | スペイン語（メキシコ） | `es_AR` | スペイン語（アルゼンチン） |
| `pt_BR` | ポルトガル語（ブラジル） | `en_US` | 英語（アメリカ） |
| `en_AU` | 英語（オーストラリア） | `ru_RU` | ロシア語 |

変更後は `LoLAPIGet.exe` を再起動し、OBSのブラウザソースも更新してください。JSONの取得時にも設定は読み込まれますが、再起動するとアプリの言語表示も更新されます。

JSONはオーバーレイから要求されたときにData Dragonから取得し、`json/<言語コード>/` に保存します。言語を変更しても他の言語のキャッシュは上書きされません。個別チャンピオンのデータは `/champion/Aatrox` のようなURLで取得できます。

## 更新

アプリの「更新」タブでオーバーレイ、実行ファイル、Data Dragonの状態を確認できます。更新後はOBSのブラウザソースを再読み込みしてください。

### オーバーレイ

「オーバーレイを最新化」はGitHub Pagesで公開されたHTML・CSS・JavaScriptを取得します。exe、assets、JSON、設定ファイルは更新しません。起動時に公開版と照合し、差分がある場合にボタンが有効になります。通信に失敗した場合はボタンから再試行できます。

更新対象の公式CSSがローカルと異なる場合は、上書き前にexeと同じフォルダーへ `.overlay-css-backup-*` フォルダーを作成して確認を表示します。キャンセルすると更新全体を中止しますが、バックアップは残ります。必要な編集を `css/custom/LoLOverlay.custom.css` に移行し、確認後に不要なバックアップを手動で削除してください。現在の公式HTMLはカスタムCSSを自動で読み込まないため、[カスタマイズガイド](カスタマイズガイド.md)に従って参照を追加してください。

### 実行ファイル

公開されたexeとの更新確認にはGitHub Pagesの `app-update.json` を使用し、実行中のexeと公開exeのSHA-256を比較します。更新がある場合はGitHub Releaseを案内します。exeは自動更新されないため、[Releases](https://github.com/comaneci-lab/lol-overlay/releases)から取得してください。

### assets・JSON

「assets・JSONを最新化」は `config/data_dragon_assets.json` に定義した画像を `assets` にマージ上書きし、全言語のJSONキャッシュを無効化します。JSONは次回の要求時に再取得されます。アーカイブにないファイルや観戦データ、設定対象外の独自画像は削除されません。

適用済みバージョンが最新版ならボタンは無効です。ただし、設定された画像フォルダーが存在しないか空の場合は、同じバージョンでも更新できます。適用済みが公開版より新しい場合はダウングレードを防ぐため更新できません。状態を取得できない場合は手動更新できます。

## トラブルシューティング

### 情報が表示されない

- `LoLAPIGet.exe` が起動中で、対応するゲームモードの試合データを取得できることを確認します。機能ごとの表示条件は[カスタマイズガイド](カスタマイズガイド.md#ゲームモードごとの表示)と[OBS設定手順](OBS設定手順.md)を参照してください。
- OBSのURL、幅・高さ、ソースの表示状態を確認し、ブラウザソースを更新します。HTMLをブラウザで確認する場合もファイルを直接開かず、同じ `http://127.0.0.1:8888/html/...` のURLを使います。
- 観戦中の手動入力については[観戦モードの使い方](観戦モード.md)を参照してください。

### アイコンが表示されない

`settings.ini` の言語がクライアントと一致しているか、配布物の画像ファイルが揃っているか確認してください。必要に応じて「更新」タブからassets・JSONを最新化し、OBSのブラウザソースを更新します。通信や更新でエラーが表示された場合は、その内容を確認してから再試行してください。
