# 横型・縦型の全体オーバーレイ設定

横型・縦型の全体オーバーレイは、複数の表示機能を1つのブラウザーソースにまとめたHTMLです。個別HTMLより設定項目が多いため、まずは[個別HTML](OBS設定手順.md#htmlファイル別の幅高さ)を使う方法をおすすめします。

## 使用するHTML

- 横型: `html/LoL_Overlay_Landscape.html`（初期サイズ 1920×1080）
- 縦型: `html/LoL_Overlay_Portrait.html`（初期サイズ 1080×1920）

OBSのブラウザーソースで使用するHTMLを選び、幅と高さを上記サイズに設定してください。OBSの基本（キャンバス）解像度と異なる場合は、以下の手順で各サイズを揃えます。

## キャンバスサイズを合わせる

1. OBSの「設定」→「映像」で、基本（キャンバス）解像度を配信・録画で使うサイズに設定します。
2. ブラウザーソースのプロパティで「幅」「高さ」をその解像度に合わせます。
3. 対応する個別CSSファイルをテキストエディターで開き、`:root` の `--canvas-width` と `--canvas-height` を同じ値にします。
   - 横型: `css/individual/LoL_Overlay_Landscape.css`
   - 縦型: `css/individual/LoL_Overlay_Portrait.css`

```css
--canvas-width: 1920px;
--canvas-height: 1080px;
```

縦型の標準サイズは幅 `1080px`、高さ `1920px` です。初期サイズのまま使う場合はCSSを変更する必要はありません。映像サイズを変更した場合は、OBSの基本解像度、ブラウザーソースの幅・高さ、CSSのキャンバスサイズを揃えてください。

## 表示位置と大きさを調整する

同じ個別CSSファイルの `:root` にある値を変更します。

| 設定項目 | 調整できる内容 |
| --- | --- |
| `--topbar-top`、`--topbar-left`、`--topbar-scale` | トップバーの上下・左右位置と拡大率 |
| `--gold-chart-left`、`--gold-chart-bottom`、`--gold-chart-scale` | ゴールドグラフの左右・下位置と拡大率 |
| `--scoreboard-left`、`--scoreboard-bottom`、`--scoreboard-scale` | スコアボードの左右・下位置と拡大率 |
| `--role-gold-diff-top`、`--role-gold-diff-right`、`--role-gold-diff-scale` | レーン別ゴールド差の上・右位置と拡大率 |
| `--active-player-cs-top`、`--active-player-cs-right`、`--active-player-cs-scale` | 分間CSの上・右位置と拡大率 |
| `--object-timer-top`、`--object-timer-right`、`--object-timer-scale` | オブジェクトタイマーの上・右位置と拡大率 |

位置は `px` 単位で調整します。拡大率は単位なしで、`1` が標準、`1.2` が1.2倍、`0.8` が0.8倍です。スコアボードの横幅を変える場合は `--scoreboard-width` と `--scoreboard-display-width` も調整してください。

横型と縦型は別のHTML・CSSファイルです。両方を使う場合は、それぞれのファイルを調整してください。変更後はOBSでブラウザーソースを再読み込みし、表示位置や見切れがないか確認します。

## 個別機能の表示・非表示を切り替える

全体オーバーレイは、HTMLから個別のJavaScriptファイルを読み込んで機能を表示しています。使いたい機能の読み込み行を追加すると表示対象になり、削除するとその機能を停止できます。

### 編集するHTML

- 横型: `html/LoL_Overlay_Landscape.html`
- 縦型: `html/LoL_Overlay_Portrait.html`

OBSで使っているHTMLを編集します。横型と縦型の両方で機能を使いたい場合は、両方のHTMLを編集してください。

### 機能とJavaScriptファイル

| 機能 | 読み込むファイル | 初期状態で読み込まれるHTML |
| --- | --- | --- |
| 共通データ・ゲーム情報 | `js/LoL_Api.js` | 横型・縦型 |
| ゴールド差グラフ | `js/LoL_GoldChart.js` | 横型・縦型 |
| スコアボード | `js/LoL_ScoreBord.js` | 横型・縦型 |
| レーン別ゴールド差 | `js/LoL_RoleGoldDiff.js` | 横型 |
| トップバー | `js/LoL_TopBar.js` | 横型・縦型 |
| 分間CS | `js/LoL_CSPerMinute.js` | 横型 |
| オブジェクトタイマー | `js/LoL_ObjectTimer.js` | 横型・縦型 |
| スキルレベルアップ時のアイコン表示 | `js/LoL_SkillLevelUp.js` | 横型・縦型。単独表示は `html/LoL_SkillLevelUp_Overlay.html` |

`LoL_Api.js` は他の機能が利用する共通ファイルです。個別の表示機能を停止する場合も、このファイルは削除しないでください。

### 機能ごとのHTML要素

一部の機能は、JavaScriptの読み込み行だけでなく、`<body>` 内の表示用 `div` も使います。機能を削除するときは、対応する要素も削除してください。

| 機能 | HTML内の表示用要素 | 要素の場所 |
| --- | --- | --- |
| ゴールド差グラフ | `<div id="goldChart"></div>` | `#overlay-canvas` の内側 |
| スコアボード | `<div class="scoreboard-widget"> ... <div id="ScoreBord"></div> ... </div>` | `#overlay-canvas` の内側。`scoreboard-scale-frame` も含めて外側の `scoreboard-widget` を削除します。 |
| レーン別ゴールド差 | `<div class="role-gold-diff-widget"><div id="RoleGoldDiff"></div></div>` | `#overlay-canvas` の内側 |
| 分間CS | `<div id="active-player-cs" class="active-player-cs" hidden></div>` | `#overlay-canvas` の内側 |
| トップバー | 固定の表示用 `div` はありません | JSが `#overlay-canvas` に追加します。 |
| オブジェクトタイマー | 固定の表示用 `div` はありません | JSが `#overlay-canvas` に追加します。 |
| スキルレベルアップ時のアイコン表示 | 固定の表示用 `div` はありません | JSが `#overlay-canvas` に追加します。 |

`#overlay-canvas` は複数機能で共有しています。機能を個別に削除するときに、この要素自体は削除しないでください。

### 表示機能を追加・削除する

1. `html/LoL_Overlay_Landscape.html` または `html/LoL_Overlay_Portrait.html` をテキストエディターで開きます。
2. `<script src="../js/` を検索して、JavaScriptの読み込み行を見つけます。
3. 機能を追加する場合は該当する読み込み行を追加し、停止する場合はその行を削除します。
4. 対応する表示用 `div` が上の表にある場合は、同じHTML内でも追加または削除します。
5. ファイルを保存し、OBSで対象のブラウザーソースを再読み込みします。

たとえば、縦型でレーン別ゴールド差を表示する場合は、`LoL_Api.js` の後、HTML内の初期化用 `<script>` より前に次の読み込み行を追加します。

```html
<script src="../js/LoL_RoleGoldDiff.js"></script>
```

さらに、`<body>` 内の `#overlay-canvas` に次の表示用要素を追加します。

```html
<div class="role-gold-diff-widget">
    <div id="RoleGoldDiff"></div>
</div>
```

HTMLの `<script>` タグ全体や他のJavaScriptの行は削除しないでください。表の「初期状態で読み込まれるHTML」に記載された機能は、初期状態ですでに読み込み行や表示用要素があるため追加不要です。

分間CSを停止する場合は、横型HTMLから該当するJavaScript読み込み行と表示用 `div` のみを削除します。

```html
<script src="../js/LoL_CSPerMinute.js"></script>
```

```html
<div id="active-player-cs" class="active-player-cs" hidden></div>
```

トップバーやオブジェクトタイマーなど、JSが表示要素を作る機能では、HTML内に対応する固定の `div` はありません。新しい機能用のJavaScriptファイルが用意されていない場合、読み込み行の追加だけでは機能を追加できません。

変更後に表示されない場合は、OBSが編集したHTMLを参照していること、読み込み行のファイル名が正しいこと、対象のファイルが `js/` にあることを確認してください。
