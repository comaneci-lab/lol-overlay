# LoL Overlay の OBS 設定手順

## 1. LoL Overlay を準備する

1. GitHub Releases からダウンロードしたZIPファイルを展開します。
2. 展開したフォルダー内のファイルやフォルダーは、移動・削除せず同じ場所に置いてください。HTML、CSS、画像、JavaScriptは `LoLAPIGet.exe` と同じフォルダー内のものを使います。これらのファイルは直接編集できます。
3. League of Legends を起動して試合に参加します。
4. `LoLAPIGet.exe` を起動します。データ取得中はウィンドウを開いたままにしてください。

## 2. OBS にブラウザソースを追加する

1. OBS Studio を起動し、オーバーレイを表示したいシーンを選択します。
2. 「ソース」欄の **＋** をクリックし、「ブラウザ」を選択します。
3. ソース名を入力します（例：`LoL Overlay`）。新しいソースを作成して「OK」をクリックします。
4. ブラウザソースのプロパティで、次のように設定します。
   - **「ローカルファイル」**のチェックを外します。
   - URLに `http://127.0.0.1:8888/html/LoL_Overlay_Landscape.html` を入力します。縦型や個別のオーバーレイを使う場合は、末尾を該当するHTMLファイル名に置き換えてください。
     HTMLファイル名は `LoLAPIGet.exe` の「管理」タブで確認できます。各ファイルの「コピー」でURLをコピーするか、「Open」で表示を確認できます。
   - **「幅」「高さ」**を、下の一覧に合わせて指定します。
   - **「表示されていない時にソースをシャットダウンする」**にチェックを入れます。
   - **「シーンがアクティブになったときにブラウザを更新する」**にチェックを入れます。
5. 「OK」をクリックしてプロパティを保存します。
6. あとはOBS上ですきなところに配置してください。

### 管理タブからOBSを操作する

同じPCのOBS Studioで「ツール」→「WebSocketサーバー設定」を開き、WebSocketサーバーを有効にしてください。認証を使用する場合はパスワードも確認します。`LoLAPIGet.exe` の「設定」タブにポート番号（通常は4455）とパスワードを入力し、「OBSに接続」を押します。

接続に成功するとポートが `settings.ini` に保存されます。パスワードを入力した場合は保存するか確認し、「はい」を選ぶとWindows資格情報マネージャーに保存します。「いいえ」を選んだ場合やパスワードが空の場合は、以前に保存したパスワードを変更しません。接続に失敗した場合、ポートもパスワードも保存しません。保存済みパスワードを削除するには、接続を解除して「保存済みパスワードを削除」を押します。接続解除時は入力中のパスワードを消去し、保存済みのものがあれば再読み込みします。

保存済みパスワードがある場合はアプリ起動時に自動接続します。OBSが未起動、WebSocketが無効、またはポートが違う場合など、接続できないときは接続待ちを表示し、10秒ごとに回数の上限なく再試行します。接続待ち中は「再試行を停止」で再試行を停止でき、設定を変更した場合も停止します。認証失敗の可能性がある場合や設定の読み込みに失敗した場合は再試行を停止するため、設定を確認して手動で接続してください。手動で接続解除した場合、次回のアプリ起動まで自動接続しません。起動時の自動接続や接続後の再接続ではパスワードの保存確認は表示しません。手動接続が待機を経て初めて成功した場合は保存を確認します。

Windows資格情報は同じWindowsユーザーの他のプログラムから利用される可能性があります。別PCや別ユーザーへの移行時は、パスワードを再入力してください。接続に成功しても設定の保存に失敗した場合は、その旨をエラーとして表示します。

各HTML行の「追加」「表示」「非表示」「削除」で、OBSの現在のシーンを操作できます。スタジオモードではプレビューシーンが対象です。追加するブラウザソースの名前は拡張子 `.html` を除いたファイル名です。OBS内に同名のソース、シーン、グループがある場合、「追加」は無効になります。操作できるのは対象シーン直下の、対応するローカルURLを設定したブラウザソースです。削除は対象シーンの該当アイテムすべてに対して行い、グループ内や他シーンのアイテムは対象外です。最後の配置を削除すると、ソース自体も削除される場合があります。

状態は接続時、「一覧を更新」時、および操作時に確認します。接続成功後は定期的な確認を行わないため、OBSが終了しても次の一覧更新や操作までは検知しません。これらの操作時に接続できないと判明した場合は自動再接続します。OBS側でシーンやソースを変更した場合は「一覧を更新」で最新状態を表示できます。操作時に表示と実際の状態が異なる場合はエラーを表示し、最新状態に更新します。失敗した操作は自動的に再実行しません。操作が一部反映された可能性がある場合はOBSで確認してください。

### HTMLファイル別の幅・高さ

以下はHTML内で指定されているキャンバス、またはウィジェットの寸法です。個別HTMLを使う場合、表示したい機能ごとにブラウザーソースを追加してください。OBSのブラウザーソースにも該当する幅・高さを入力します。全体オーバーレイを使う場合は[横型・縦型オーバーレイの設定](横型・縦型オーバーレイ.md)も参照してください。

サイズは実行ファイルと同じ場所にある `config/overlay_sizes.json` で管理し、ソース追加時に読み込みます。幅・高さを変更しても既存のOBSソースには反映されません。JSONは「オーバーレイを最新化」の対象外です。配布版の更新時は、必要に応じて配布物の `config` フォルダーも配置してください。設定ファイルがない場合や形式が不正な場合は、エラーを表示して追加を中止します。

この表を更新する場合はJSONを編集し、リポジトリのルートで `python -m scripts.generate_obs_size_docs` を実行してください。`--check` を付けると表が最新か確認できます。`width` と `height` を両方 `null` にすると固定値なしとして扱います。

個別表示では、ゴールドチャート、スコアボード、レーン別ゴールド差、分間CS、オブジェクトタイマー、トップバー、スキルレベルアップの各ウィジェットが、OBSブラウザーソースの幅・高さの中央に表示されます。表示内容がソース領域を超える場合は、OBS側で幅・高さを調整してください。

スコアボード、トップバー、ゴールドチャートは、試合の `GameStart` イベントを取得してから表示されます。横型・縦型の全体オーバーレイでも同様です。

ゴールドチャートの下にはORDERとCHAOSのイベント行が表示されます。チャンピオンキルはチーム別に30秒ごとに集約し、件数に応じてチーム色の丸を大きく表示します。タワー、ヴォイドグラブ、ドラゴン、ヘラルド、バロンはアイコンで表示します。行の背景は自チーム色・相手色に合わせ、観戦時はORDERを自チーム色、CHAOSを相手色として扱います。イベント行の高さは固定で、重なった場合はキルよりアイコンを手前に表示し、アイコン同士では後のイベントを手前に表示します。

チャート全体には共通の半透明背景があり、その上にチームの背景色が重なります。共通背景色はCSS変数 `--chart-background` で変更できます。

時間軸には試合内時刻を使用し、初期表示は0〜25分です。25分以降は1分ごとに右端を1分ずつ伸ばします。縦軸は1,000G間隔で罫線を表示し、記録したゴールド差が表示範囲の端に達すると1,000G単位で範囲を広げます。途中から表示した場合、APIで取得できるイベント履歴は表示しますが、それ以前のゴールド推移は表示できません。観戦時も時刻とチームを特定できるイベントのみ表示し、手動入力の取得数から過去の時刻は推測しません。既存のOBSソースには新しい推奨サイズが自動反映されないため、個別のゴールドチャートは高さを210以上に変更してください。

「固定値なし」のHTMLは、表示内容や調整により必要な範囲が変わります。ブラウザソースの幅・高さを設定した後、OBSプレビューで表示が切れないサイズに調整してください。

チャンピオンマップでは3レーンのミニオンと各タワーを表示します。キャノンミニオンは大きく表示され、ミニオン同士の衝突位置は各チームの残存タワーの前線の中間になります。ミニオンは衝突や敵タワーへの到達後に消え、破壊されたタワーは `TurretKilled` イベントに応じて表示から取り除かれます。

タワーとミニオンの表示は、`js/LoL_ChampionMap.js` の `teamMarkerVisibilitySettings` で味方・敵ごとに切り替えられます。`true` が表示、`false` が非表示です。

```js
const teamMarkerVisibilitySettings = {
    TOWER: { ALLY: true, ENEMY: true },
    MINION: { ALLY: true, ENEMY: true }
};
```

設定を変更した後は、OBSのブラウザソースを更新してください。

## 3. 表示を確認する

試合中にOBSのプレビューでオーバーレイが表示されることを確認します。表示されない場合は、`LoLAPIGet.exe` が起動していること、試合中であること、ブラウザソースのURLが正しいことを確認してください。確認後、ブラウザソースを右クリックして「更新」を試してください。

HTMLをChromeで直接確認するときも、ファイルを直接開かず、同じURL（例：`http://127.0.0.1:8888/html/LoL_Overlay_Landscape.html`）を開いてください。HTMLやJavaScriptを編集した後は、ブラウザまたはOBSのソースを更新すると変更が反映されます。

## 補足

- 全体オーバーレイのキャンバスサイズや表示位置を調整する場合は、[横型・縦型オーバーレイの設定](横型・縦型オーバーレイ.md)を参照してください。
- OBS を終了するときは、`LoLAPIGet.exe` のウィンドウも閉じてください。
