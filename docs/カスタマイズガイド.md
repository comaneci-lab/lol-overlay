# カスタマイズガイド

## 既存オーバーレイを改造する際の注意

公式HTML・CSS・JavaScriptを直接編集すると、オーバーレイの最新化や配布版の入れ替えで変更が失われることがあります。次の手順で改造用ファイルを分けてください。

1. 使用するHTMLを `html` 内に別名でコピーします。変更するJSやCSSも、それぞれ元のファイルと同じフォルダー内に別名でコピーします。色や配置の上書きには、コピーの代わりに後述のカスタムCSSも使えます。
2. コピーしたHTML内の `<script>` や `<link>` の参照先を、変更したファイルの名前に合わせます。共通ファイルなど、コピーしていないファイルの参照はそのまま残してください。
3. OBSのブラウザソースにはコピーしたHTMLのURLを指定します。編集後はソースを再読み込みし、表示や動作を確認します。試合中の履歴を記録するソースでは、再読み込みによって履歴がリセットされる点に注意してください。
4. 独自ファイルは配布ファイルと重複しない名前にし、別の場所にもバックアップします。オーバーレイ更新は公開一覧のファイルを上書きするため、独自ファイルと同名の公式ファイルが将来追加されると衝突する可能性があります。
5. 公式ファイルを更新しても、別名のコピーには修正が自動反映されません。更新後は元ファイルの変更を確認し、必要な修正をコピーに取り込んでください。配布版の入れ替え時にも独自ファイルと参照先が残っているか確認します。

独自の個別オーバーレイを新規作成する場合は、[個別オーバーレイ開発ガイド](個別オーバーレイ開発ガイド.md)を参照してください。

## 色や配置を変更する

公式CSSを直接編集すると更新時に上書きされるため、`css/custom/LoLOverlay.custom.css` に変更を記述してください。このファイルはオーバーレイ更新の対象外です。起動時の更新確認でファイルがない場合は空のテンプレートが作成されます。

現在の公式HTMLはこのCSSを自動では読み込みません。使用するHTMLを `html` 内に別名でコピーし、コピーしたHTMLの `</head>` より前、公式CSSの読み込み行の後に次の行を追加してください。

```html
<link rel="stylesheet" href="../css/custom/LoLOverlay.custom.css">
```

OBSにはコピーしたHTMLのURLを指定し、編集後はブラウザソースを更新してください。

横型・縦型の全体オーバーレイのキャンバス、配置、表示機能の変更は[全体オーバーレイの設定](横型・縦型オーバーレイ.md)を参照してください。

## ゲームモードごとの表示

各表示用JavaScriptの先頭付近にある `*_ALLOWED_GAME_MODES` で `gameData.gameMode` を指定します。一覧にないモードや新しいモードでは非表示になります。観戦判定、表示タイミングなど、機能ごとの他の条件も適用されます。

| 初期設定の対象モード | 機能 |
| --- | --- |
| `CLASSIC`、`PRACTICETOOL` | チャンピオンマップ |
| `CLASSIC`、`PRACTICETOOL`、`SPECTATOR` | トップバー、オブジェクトタイマー、レーン別ゴールド差、プレイヤールーン |
| 上記3モードと `ARAM` | ゴールドチャート、スコアボード、スキルレベルアップ、分間CS、試合開始スプラッシュ、試合アイテム・スキルオーダー、試合後サムネイル、チャンピオンスキル |

チャンピオンスキルの試合外の手動表示など、ゲームデータを取得できない場合の動作は別途設けられています。対応モードを追加しても、必要なデータや他の表示条件が満たされない場合は表示されません。

JSを変更するときは、[改造時の注意](#既存オーバーレイを改造する際の注意)に従ってJSとHTMLをコピーし、参照先を変更してください。

## 機能別の設定

- **スキルレベルアップ・アイテム通知**：自分のアイテムの所持数が増えてから5秒間所持し続けた場合、そのアイコンをスキルの上段に3秒間表示します。最初の取得時に所持しているアイテムは表示しません。定期比較による検知のため購入以外の増加も対象となり、取得と取り消しが取得間隔内に完了した場合は検知できません。保持時間は `js/LoL_SkillLevelUp.js` の `ITEM_PURCHASE_HOLD_DURATION` で変更できます。
- **チャンピオンマップ**：タワーとミニオンの表示は `js/LoL_ChampionMap.js` の `teamMarkerVisibilitySettings` で味方・敵ごとに切り替えられます。`true` が表示、`false` が非表示です。
